# Preparación del logotipo

El archivo original `assets/branding/customer-logo.jpeg` permanece intacto. La variante `assets/branding/customer-logo-transparent.png` se preparó con la herramienta integrada `imagegen`, en modo edición con transparencia, a petición del cliente. No se utiliza un servicio de imágenes en la aplicación instalada.

La variante conserva los textos MATERIALES / CHICONTLA / RENTA DE MAQUINARIA Y ACARREOS. Se utiliza sobre superficies claras para mantener legibles sus elementos negros. Los documentos imprimibles mantienen fondo blanco independientemente del tema personal.

Prompt de edición:

> Use case: background-extraction. Edit target: the supplied original customer logo. Prepare a faithful transparent PNG for use in desktop software and printed receipts. Remove ONLY the white background to true alpha transparency, including the white negative spaces. Preserve the exact red gear, yellow ring, black circular outline, wrench, hand, excavator, house, two small black gears, all proportions and relative placements. Preserve all original black lettering, typography and spelling EXACTLY: 'MATERIALES' / 'CHICONTLA' / 'RENTA DE MAQUINARIA Y ACARREOS'. Do not redesign, recolor, add elements, replace words, add shadows, add outlines, or distort anything. Retain clean antialiased edges and the same overall composition. Leave modest transparent outer padding. The text must remain black. Actual transparent background, never a checkerboard baked into the image.
