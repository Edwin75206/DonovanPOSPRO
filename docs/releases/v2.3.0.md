# Donovan POS Pro 2.3.0 — Windows / MySQL local

Aplicación de escritorio para Construrama Chicontla, desarrollada por Donovan Systems.

## Descargar e instalar

Descarga **DonovanPOS-2.3.0-Windows-x64-Instalador.exe** desde los adjuntos de esta versión. Incluye MySQL local, MySQL Workbench y los componentes de ejecución necesarios. Las operaciones de venta funcionan sin internet; el cliente no necesita herramientas de desarrollo.

Si ya utilizabas SQLite, el cambio a MySQL se realiza desde **Configuración → Administración de datos → Respaldar y migrar a MySQL**. La base original se conserva. Para actualizar, crea un respaldo y cierra Donovan POS Pro y Workbench antes de ejecutar el instalador.

## Comprobado

Venta desde la interfaz instalada, cambio en efectivo, inventario, folio único, sesión persistente, acceso a MySQL, respaldo/restauración y conservación de datos al reinstalar. El informe adjunto describe las pruebas y su alcance.
